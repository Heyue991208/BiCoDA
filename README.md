# BiCoDA
BiCoDA: A Bidirectional Cooperative Defect Analysis Model for Wafer Die Defect Detection and Semantic Segmentation

Wafer die defects exhibit substantial variation in scale, texture, and morphology. Although wafer die defect detection can identify defect classes and localize defects, rectangular bounding boxes are often inadequate for characterizing irregular defect boundaries. Conversely, semantic segmentation provides pixel-level delineation of defect regions but does not inherently provide reliable object-level information and localization. To address these complementary limitations, we propose BiCoDA, a Bidirectional Cooperative Defect Analysis model for wafer die defect detection and semantic segmentation. BiCoDA employs a shared feature encoder to integrate complementary spatial, frequency-domain, and edge representations, together with a hierarchical Transformer and multiscale feature encoding. Its detection and segmentation branches exchange complementary information bidirectionally: the segmentation branch provides defect-region and boundary information to enhance detection, while the detection branch supplies class and location context to guide segmentation. During inference, predicted masks guide the geometric refinement of detection boxes, and candidate predictions are reranked using detection confidence and segmentation quality. Experiments on the Wafer-Defect-rv1vx dataset demonstrate that BiCoDA achieves an mAP50 of 78.72\%, an mAP50-95 of 52.84%, a Dice  of 82.32%, and an IoU of 72.32% with 42.71 million parameters and an inference speed of 86 FPS. Ablation studies also show that bidirectional cooperation improves both detection and segmentation performance, while mask-guided geometric refinement yields additional gains in defect localization. Overall, BiCoDA provides a unified framework for defect classification, object-level localization, and pixel-level region delineation, achieving a favorable balance between detection accuracy, segmentation quality, model size, and inference efficiency.
